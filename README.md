# SAYAT CUSTOM — اپلیکیشن گروه صنعتی سایات

نسخه اولیه Expo / React Native با رابط فارسی و راست‌به‌چپ.

امکانات: صفحه اصلی، محصولات، پیکربندی ۶ مرحله‌ای، بررسی محدودیت‌های پایه، فرم درخواست و صفحه تماس.

محدودیت‌های فنی داخل `App.js` نمونه اولیه‌اند و قبل از استفاده صنعتی باید توسط واحد فنی سایات تأیید شوند.

شماره تماس و واتساپ در `App.js` تنظیم شده‌اند: 09113748915. ایمیل فعلاً خالی است.

## اجرا

```bash
npm install
npx expo start
```

## ساخت APK

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build -p android --profile preview
```


## لوگو
لوگوی رسمی ارسال‌شده برای سایات در `assets/sayat-logo.png` قرار گرفته و در هدر، صفحه اصلی و تنظیمات آیکون/صفحه شروع استفاده شده است.
